# 贪吃蛇

一款基于单个 `snake.html` 实现的贪吃蛇小游戏，支持电脑和手机游玩。游戏保留了经典玩法，同时加入了多种水果、道具效果、等级成长和速度调节，让每一局都更有变化。

## 游戏特色

- 多种普通水果：苹果、香蕉、草莓、西瓜、橘子、黄瓜、桃子
- 三种特殊道具：闪电、幽灵、钻石
- 闪电效果：临时加速并获得双倍分数
- 幽灵效果：可穿墙移动
- 钻石效果：获得三倍分数
- 等级系统：每吃满一定数量的食物会升级并加快节奏
- 连击加分：连续快速吃到食物会触发额外奖励
- 速度可调：顶部滑条可直接调节基础运行速度
- 最高分记录：会自动保存到本地浏览器
- 手机适配：支持滑动操作和屏幕方向按钮

## 操作方式

### 电脑端

- `↑ ↓ ← →` 或 `W A S D`：控制移动方向
- `空格`：暂停 / 继续
- `Esc`：暂停 / 继续

### 手机端

- 滑动屏幕：控制方向
- 方向按钮：辅助控制
- 点击屏幕：在暂停时继续游戏

## 速度调节

游戏顶部有一个“速度”滑条：

- 数值越小，贪吃蛇移动越快
- 数值越大，游戏节奏越慢
- 调节会即时生效，并会保存在浏览器本地

## 玩法说明

1. 点击“开始游戏”进入倒计时。
2. 控制贪吃蛇吃掉随机生成的水果。
3. 吃到普通水果会获得分数，不同水果分值不同。
4. 吃到特殊道具会触发额外能力。
5. 随着等级提升，速度会逐渐增加。
6. 撞墙或撞到自己的身体会结束游戏。

## 文件说明

- `snake.html`：游戏主文件，包含页面结构、样式和全部逻辑

## 运行方式

1. 直接用浏览器打开 `snake.html`
2. 点击“开始游戏”
3. 也可以把仓库部署到 GitHub Pages 后在线游玩
